Safe to install, even when your device asks firstAndroid and Windows ask about any app from outside Google Play or the Microsoft Store, simply because they have not met it yet.
  • Open source: every line on GitHub
  • Every update signed with the same key
  • A SHA-256 checksum for every file
  • No adverts, no tracking, no account

Installing on Android

About a minute · real screens
  1. 1DownloadTap Download the APK, then tap the file.
  2. 2Your phone asks firstTap Settings.
  3. 3Allow from this sourceTurn it on, then go back.
  4. 4InstallTap Install.
  5. 5OpenMiftāḥ is ready. Updates come from inside the app.

If Google Play Protect asks, tap Scan app. It checks Miftāḥ and finds nothing; then tap Install.

Installing on Windows

About a minute · no administrator
  1. 1DownloadChoose Download the installer. If your browser asks, choose Keep.
  2. 2Windows asks firstChoose More info.
  3. 3Run anywayWindows has not met Miftāḥ yet, so the publisher shows as unknown.
  4. 4InstallChoose a desktop shortcut if you want one, then Install. No administrator needed.
  5. 5OpenMiftāḥ is in the Start menu. Updates come from inside the app; remove it from Settings › Apps like any program.

    Why it exists

    Knowledge, kept and passed on

    ٱلَّذِى عَلَّمَ بِٱلْقَلَمِ ۝ عَلَّمَ ٱلْإِنسَـٰنَ مَا لَمْ يَعْلَمْ

    Who taught by the pen, taught humanity what they knew not. Al-ʿAlaq 96:4–5 · The Clear Quran

    No adverts, no account, no tracking. A family’s record lives on its own devices and moves between them only on the family’s own Wi-Fi, or in a file they send themselves. The code is open, so anyone can check it, learn from it and make it better.

    Verified sourcesThe Qurʾān byte for byte from Tanzil, its translation from The Clear Quran, duʿāʾ from Ḥiṣn al-Muslim. Never clipped, never a game.
    Honest learningA lesson counts only when the child shows it alone. Paper and on-screen work count only once a grown-up marks it.
    PrivateLearning data stays on your devices. Phone and computer talk only at home, sealed with a key they alone share.
